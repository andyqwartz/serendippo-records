# HzMycelium

## Plus d'infos, contacts et documentation complète : https://hzmycelium.xyz / [Tutoriel vidéo ICI](https://youtu.be/1YBza27BO70)

HzMycelium est un générateur de sites pour artistes underground, fonctionnant localement et uniquement grâce à un script Python.
Le script remplit des fichiers templates HTML et CSS à partir d'une arborescence de dossiers et de fichiers, et de paramètres écrits dans des fichiers de configuration en .txt.

Lancer le script :
```bash
python main.py -af artist -of site build 
```

• -af / -artistfolder : chemin du dossier dans lequel sont organisés les fichiers

• -of / -outputfolder : nom du dossier à générer en sortie
